# แต่งห้อง Furdini

หน้าเว็บให้ลูกค้าลองแต่งห้องด้วยเฟอร์นิเจอร์ Furdini 4 คอลเลกชัน (MARU, KEEPER PLUS+, NATURA, VERTA) รวม 32 รายการ

- เริ่มจากเลือกห้อง: ห้องนั่งเล่น ห้องนอน ห้องเด็ก ห้องทำงาน หรือห้องว่าง (จัดตามแบบแนะนำ หรือเริ่มจากห้องว่าง)
- มุมมอง ผังห้อง (2D มองบน) · หน้าตรงผนัง (2D ทีละผนัง) · 3D หมุนรอบห้อง
- วางตู้บนผนังซ้าย หลัง ขวา ดูดชิดชิ้นข้างๆ บอกช่องมุมที่ตู้ผนังข้างเคียงใช้อยู่ และเตือนเมื่อชนกัน
- ประตู หน้าต่าง ประตูบานเลื่อน + ผ้าม่าน (ทึบ / โปร่ง / ทึบ+โปร่ง, 6 สี)
- ของตกแต่งบนตู้: ทีวี 43/55/65", ต้นไม้, แจกัน, หนังสือ, กรอบรูป, โคมไฟ, ภาพแขวนผนัง (วางบนท็อปตู้อัตโนมัติ, บนชุดตู้ทีวีวางที่ช่องทีวี)
- ของวางพื้น: พรม 3 ขนาด 6 สี, โซฟา, อาร์มแชร์, โต๊ะกลาง, เตียง 5 ฟุต / 3.5 ฟุต, เก้าอี้ทำงาน, ต้นไม้ใหญ่
- รายการสินค้า ราคาปกติ/ราคาพิเศษ ยอดรวม และสร้างภาพแผนห้อง (3D + รายการ) เป็น PNG

ไฟล์: index.html (โค้ด + ข้อมูลสินค้า), img/ (ภาพสินค้า รหัส.webp ตัดจากแคตตาล็อก และ room-*.jpg ภาพ inspire)
